01 / Problem

Terminal tabs don't scale

Lost work

Agents overwrite each other

Two sessions on one repo, and one quietly undoes the other's changes. You find out at review time, if you find out at all.

Dead sessions

Close the lid, lose the run

Local sessions die with your laptop. Anything long running means babysitting an open terminal on a machine that has to stay awake.

Blind spots

One tool, one window

Claude in one window, Codex in another, a teammate running something you cannot see at all. Nowhere to look at all of it.

02 / Setup

Three steps, no migration

1

Install on machines you already use

Run apanel link on your laptop, your VPS, the box under your desk. Each one becomes a board you can patch into. Your code never leaves it.

2

Start agents the way you already do

Prefix any agent with apanel run. Claude Code, Codex, Gemini, whatever you switch to next month. Same flags, same behaviour, now with a line on the board.

3

Watch from anything with a browser

Open the board on your phone. See what every agent is doing, read the diff, approve the risky command, redirect it, or kill it. Agents keep working with your laptop shut.
