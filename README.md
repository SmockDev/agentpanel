# agentpanel

One place to see and steer all your coding agents. Claude Code, Codex, whatever else you run.

Early days. The CLI wraps an agent in a real terminal and keeps a copy of the session. Watching it from your phone is the next piece.

```
npm i -g @smockdev/agentpanel
apanel run -- claude
```

- `cli/` the npm package, [@smockdev/agentpanel](https://www.npmjs.com/package/@smockdev/agentpanel)
- `landing/` the site
